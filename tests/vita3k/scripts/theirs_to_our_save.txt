# Drive THEIR build from a cold config to the SAME save our port reaches.
#
# Goal (HANDOVER §7.4b): our build and theirs have never been compared on the same scene, so no pixel
# comparison has been valid. Their build reads the SAME GCI our build writes --
# ux0:data/TwilitRealm/Dusklight/EUR/Card A/01-GZ2P-gczelda2.gci -- so loading save slot 1 on both
# sides is the way to make the comparison like-for-like.
#
# CONFIRM IS CIRCLE (`c`), NOT CROSS (`x`). Source: map_pad_button() gives PAD_BUTTON_A -> KI_RETURN
# (ui/input.cpp:171), map_nav_event() turns KI_RETURN into NavCommand::Confirm (ui/ui.cpp:647), and
# this UI prints an "A/B/X/Y" layout. Cross is the east button = B = Cancel. Proven by run cc_.
#
# Precondition: config.json holds ONLY the disc path and no backend.wasPresetChosen, so the preset
# modal is up at first frame. /tmp/theirs-config.json.bak-* holds the two-key original.
#
# This is a wall-clock script: the sequence is fixed, the timing is not. Every wait below is generous
# because software GL runs this at a few frames per second, and a fixed frame number would be a lie.

# --- disc boot: GC logo, then the title screen --------------------------------
wait 25
